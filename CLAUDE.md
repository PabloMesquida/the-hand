# Proyecto mano

Mano rigueada detrás de un vidrio esmerilado que se deforma como tela (three.js). Hablar en español.

- Usar **WebGPU + TSL** (`three/webgpu`, `three/tsl`), nunca WebGL/GLSL.
- Seguir la estructura de las lecciones de Bruno Simon en `C:\proyectos\lessons` (secciones `/** */` en `script.js`, clases en archivos aparte, GUI con `renderer.inspector`).
- Blender 5.2 está en `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe` (usar `-b --python`). No hay Python en el sistema.
- **Al terminar un paso importante, agregar una entrada a `BITACORA.md`** (qué se pidió, qué se probó, qué falló y cómo se resolvió) y actualizar "Estado actual" y "Pendientes".
